# مؤشرات الرؤية — لوحة مؤشرات رؤية عُمان 2040

الرابط: https://horizons2016.github.io/vision-indicators/

## للمستخدمين: التثبيت على الجوال
- **آيفون (Safari):** افتح الرابط ← زر المشاركة ⬆︎ ← «إضافة إلى الشاشة الرئيسية».
- **أندرويد (Chrome):** افتح الرابط ← اضغط «تثبيت» في الشريط الذي يظهر، أو من القائمة ⋮ ← «تثبيت التطبيق».

التطبيق يعمل بدون إنترنت، ويتحدث تلقائياً عند فتحه مع الاتصال. لا حاجة لإعادة التثبيت بعد أي تحديث.

## للمسؤول: تحديث البيانات (بدون أي برامج)
1. افتح الرابط مضافاً إليه `#admin`، وأدخل **رمز الإدارة**:
   https://horizons2016.github.io/vision-indicators/#admin
   (يبقى الجهاز في وضع الإدارة حتى تضغط «خروج من وضع الإدارة».)
2. نزّل نموذج Excel من الصفحة (أو استخدم آخر نسخة لديك)، وحدّث القراءات فيه.
3. ارفع الملف في صفحة الإدارة. تظهر الأخطاء والفروق قبل أي اعتماد.
4. افتح وضع التحليل (`#analysis`)، ثم إذا كانت النتيجة سليمة اضغط «تنزيل dataset.json» (يُنزَّل معه `internal.enc`).
5. في GitHub افتح المجلد `data` ← Add file ← Upload files ← اسحب الملفين `dataset.json` و`internal.enc` ← Commit changes.
6. خلال دقيقة إلى دقيقتين يتحدّث الموقع عند الجميع.

صلاحية النشر هي حساب GitHub فقط؛ صفحة الإدارة تفحص وتعاين ولا تنشر شيئاً بنفسها.

## الصلاحيات والأوضاع
| الوضع | الدخول | ماذا يرى |
|---|---|---|
| **عام (اطلاع)** | الرابط مباشرة | القراءات والمستهدفات والمصادر وتقويم الإصدارات، ومشاركة أي مؤشر بزر «نسخ» أو «صورة» (PNG) أو «PDF»؛ يُنشأ الملف مباشرة، وعلى الجوال تظهر قائمة المشاركة. لا تصنيفات ولا نسب تقدم ولا توقعات، ولا مشاركة بالروابط. |
| **تحليل** | الرابط + `#analysis` + رمز التحليل | إضافة إلى ذلك: تصنيف المسار، Progress Ratio، التوقعات، والبيانات الداخلية لبطاقات المؤشرات. يبقى مفعّلاً على الجهاز حتى «خروج». |
| **إدارة** | الرابط + `#admin` + رمز الإدارة | تصدير النتائج، نموذج Excel، فحص ملفات التحديث، وتنزيل ملفات النشر (يتطلب فتح وضع التحليل أيضاً). |

- البيانات الداخلية (تقدير عدم التحقق، ملاحظات المراجعة، حالة الاعتماد، نصوص البطاقات، الجهة المالكة، الملاحظات السنوية) **ليست** في `data/dataset.json`، بل في `data/internal.enc` مشفّرة، ولا تُفك إلا برمز التحليل.
- الرموز لا تُحفظ في المستودع: رمز الإدارة بصمة SHA-256 فقط، ورمز التحليل هو مفتاح التشفير نفسه.
- عند النشر من صفحة الإدارة يُنزَّل ملفان (`dataset.json` و`internal.enc`): ارفعهما معاً إلى مجلد `data`. إن سأل المتصفح عن السماح بتنزيل أكثر من ملف فاختر «سماح».

## محتويات المستودع
| الملف | الوظيفة |
|---|---|
| `index.html` | واجهة اللوحة (لا تحتوي بيانات) |
| `data/dataset.json` | البيانات العامة: المؤشرات والقراءات والمستهدفات |
| `data/internal.enc` | البيانات الداخلية مشفّرة (تُفك برمز التحليل) |
| `tools/seal.mjs` | فصل البيانات الداخلية وتشفيرها، والتحقق من خلو الملف العام منها |
| `sw.js` · `manifest.webmanifest` · `icons/` | التثبيت على الجوال والعمل بدون إنترنت |

لا تغيّر اسم المستودع: تغييره يغيّر الرابط، فيحتاج من ثبّت التطبيق إلى تثبيته من جديد.
