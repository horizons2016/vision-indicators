# مؤشرات الرؤية — لوحة مؤشرات رؤية عُمان 2040

الرابط: https://horizons2016.github.io/vision-indicators/

## للمستخدمين: التثبيت على الجوال
- **آيفون (Safari):** افتح الرابط ← زر المشاركة ⬆︎ ← «إضافة إلى الشاشة الرئيسية».
- **أندرويد (Chrome):** افتح الرابط ← اضغط «تثبيت» في الشريط الذي يظهر، أو من القائمة ⋮ ← «تثبيت التطبيق».

التطبيق يعمل بدون إنترنت، ويتحدث تلقائياً عند فتحه مع الاتصال. لا حاجة لإعادة التثبيت بعد أي تحديث.

## للمسؤول: تحديث البيانات (بدون أي برامج)
1. افتح الرابط مضافاً إليه `#admin`:
   https://horizons2016.github.io/vision-indicators/#admin
2. نزّل نموذج Excel من الصفحة (أو استخدم آخر نسخة لديك)، وحدّث القراءات فيه.
3. ارفع الملف في صفحة الإدارة. تظهر الأخطاء والفروق قبل أي اعتماد.
4. إذا كانت النتيجة سليمة اضغط «تنزيل dataset.json».
5. في GitHub افتح المجلد `data` ← Add file ← Upload files ← اسحب ملف `dataset.json` ← Commit changes.
6. خلال دقيقة إلى دقيقتين يتحدّث الموقع عند الجميع.

صلاحية النشر هي حساب GitHub فقط؛ صفحة الإدارة تفحص وتعاين ولا تنشر شيئاً بنفسها.

## محتويات المستودع
| الملف | الوظيفة |
|---|---|
| `index.html` | واجهة اللوحة (لا تحتوي بيانات) |
| `data/dataset.json` | كل البيانات: المؤشرات والقراءات والمستهدفات |
| `sw.js` · `manifest.webmanifest` · `icons/` | التثبيت على الجوال والعمل بدون إنترنت |

لا تغيّر اسم المستودع: تغييره يغيّر الرابط، فيحتاج من ثبّت التطبيق إلى تثبيته من جديد.
