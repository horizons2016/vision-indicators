# مؤشرات الرؤية — لوحة مؤشرات رؤية عُمان 2040

الرابط: https://ov2040.github.io/vision-indicators/

## للمستخدمين: التثبيت على الجوال
- **آيفون (Safari):** افتح الرابط ← زر المشاركة ⬆︎ ← «إضافة إلى الشاشة الرئيسية».
- **أندرويد (Chrome):** افتح الرابط ← اضغط «تثبيت» في الشريط الذي يظهر، أو من القائمة ⋮ ← «تثبيت التطبيق».

التطبيق يعمل بدون إنترنت، ويتحدث تلقائياً عند فتحه مع الاتصال. لا حاجة لإعادة التثبيت بعد أي تحديث.

## للمسؤول: تحديث البيانات (بدون أي برامج)
1. افتح الرابط مضافاً إليه `#admin`، وأدخل **رمز الإدارة**:
   https://ov2040.github.io/vision-indicators/#admin
   (يبقى وضع الإدارة فعّالاً داخل التبويب نفسه حتى إغلاقه أو الضغط على «خروج من وضع الإدارة»، ويُطلب الرمز من جديد في كل تبويب جديد.)
2. نزّل نموذج Excel من الصفحة (أو استخدم آخر نسخة لديك)، وحدّث القراءات فيه.
3. ارفع الملف في صفحة الإدارة. تظهر الأخطاء والفروق قبل أي اعتماد.
4. إذا كانت النتيجة سليمة اضغط «تنزيل dataset.json».
5. في GitHub افتح المجلد `data` ← Add file ← Upload files ← اسحب ملف `dataset.json` ← Commit changes.
6. خلال دقيقة إلى دقيقتين يتحدّث الموقع عند الجميع.

صلاحية النشر هي حساب GitHub فقط؛ صفحة الإدارة تفحص وتعاين ولا تنشر شيئاً بنفسها.

## الصلاحيات
- **المستخدم (اطلاع):** يتصفح المؤشرات، ويشارك أي مؤشر من بطاقته بزر «نسخ» (نص جاهز للإرسال) أو «صورة» (PNG) أو «PDF»؛ يُنشأ الملف مباشرة ويُحفظ في التنزيلات، وعلى الجوال تظهر قائمة المشاركة. لا توجد مشاركة بالروابط.
- **المسؤول:** إضافة إلى ذلك: تصدير النتائج (CSV)، تنزيل نموذج Excel و`dataset.json`، وفحص ملفات التحديث.
- رمز الإدارة يُحفظ في الكود كبصمة SHA-256 فقط (`ADMIN_HASH` في `index.html`). لتغييره اطلب بصمة الرمز الجديد واستبدلها.

## طلبات التحديث الآلية (الربط مع مستودع البيانات والتقارير)
سير العمل «طلبات تحديث المؤشرات» يعمل كل ساعتين خلال الدوام، ويقارن بيانات التطبيق بثلاثة مصادر حسب ملف الربط `config/indicator_sources.json`:
- **إصدارات المركز الوطني للإحصاء والمعلومات** كما يرصدها «مستودع البيانات والتقارير» (إصدار جديد أو تعديل صامت على ملف منشور) ← «تنبيه إصدار» فيه المؤشرات المعنية وآخر قراءاتها ورابط الملف.
- **واجهة بيانات البنك الدولي** (مؤشرات الحوكمة العالمية وغيرها) ← «طلب تحديث» بقيمة مقترحة جاهزة.
- **تقويم الإصدارات** للمؤشرات الدولية (`rel_due`) ← «تنبيه إصدار» عند حلول الموعد.

تصل الطلبات في تبويب **Issues** (ويصلك إشعار بالبريد). **الاعتماد بتعليق** من صاحب صلاحية:
- `/اعتماد` ← يعتمد القيم المقترحة في الطلب.
- `/اعتماد U-31 2026 3.0` ← يضيف أو يصحح قراءة (الرمز السنة القيمة [الترتيب])، ويمكن كتابة عدة أسطر.

بعد الاعتماد يُحدَّث `data/dataset.json` (مع المصدر)، ويُعاد بناء لوحة الإكسل المحمية ويُسجَّل التغيير، ويُرد على الطلب ويُغلق. لا يتغير أي رقم دون اعتماد. لإضافة مؤشر إلى الرصد عدّل `config/indicator_sources.json`.

## لوحة الإكسل المحمية (تلقائية)
عند كل رفع لـ`data/dataset.json` يعمل GitHub Actions («بناء ملف الإكسل») فيبني `excel/vision2040-indicators.xlsx` من البيانات نفسها، ويقارن النسخة الجديدة بالسابقة ويسجّل كل تغيير (قراءة جديدة، تصحيح، مستهدف) في `excel/changelog.json` وفي ورقة «سجل التحديثات» داخل الملف. تُنزَّل من صفحة الإدارة («تنزيل لوحة الإكسل المحمية»). كلمة مرور حماية الأوراق تُضبط في إعدادات المستودع: Settings ← Secrets and variables ← Actions ← `EXCEL_PASSWORD`.

## الدوريات (PowerPoint)
صفحة **الدوريات** (`reports.html`) تُنتج داشبورد PowerPoint في شريحة واحدة قابلة للتعديل، من نفس البيانات ونفس محرك الحساب:
- **نبض الرؤية** (كل 3 أشهر): الأرقام الرئيسية، الحالة حسب المحاور، ما الجديد خلال الربع (مقارنة تلقائية بنسخة البيانات في بداية الربع من سجل GitHub)، المؤشرات التي تحتاج تدخلاً، الإصدارات والتحديث.
- **لمحة عن الرؤية** (سنوي): الأرقام الرئيسية، الحالة حسب المحاور، التحرك مقارنة بالعام السابق، المؤشرات التي تحتاج تدخلاً، المؤشرات على المسار.

التحديث: حدّث `dataset.json` كالمعتاد ← افتح https://ov2040.github.io/vision-indicators/reports.html ← اختر الدورية والفترة ← «إنشاء ملف PowerPoint».

## محتويات المستودع
| الملف | الوظيفة |
|---|---|
| `index.html` · `js/app.js` · `js/engine.js` | واجهة اللوحة (لا تحتوي بيانات)، ومحرك الحساب المشترك مع الدوريات |
| `js/xlsx-worker.js` · `lib/xlsx.full.min.js` | قراءة ملفات Excel المرفوعة داخل عامل معزول |
| `fonts/` | الخطوط مستضافة داخل المستودع (بلا طلبات لجهات خارجية) |
| `data/dataset.json` | كل البيانات: المؤشرات والقراءات والمستهدفات |
| `reports.html` · `js/reports.js` · `reports/builder.js` · `lib/pptxgen.bundle.js` | صفحة الدوريات ومولّد شرائح PowerPoint |
| `config/indicator_sources.json` · `tools/update_requests.py` · `tools/apply_request.py` · `requests/state.json` | ربط المؤشرات بمصادرها، مولّد طلبات التحديث، آلية الاعتماد بتعليق، وحالة الرصد |
| `excel/vision2040-indicators.xlsx` | لوحة الإكسل المحمية، تُبنى تلقائياً من `dataset.json` (لا تُعدَّل يدوياً) |
| `excel/changelog.json` · `excel/template.xlsx` · `tools/build_excel.py` · `.github/workflows/build-excel.yml` | سجل التحديثات الآلي، قالب الإكسل، ومولّده الذي يعمل على GitHub عند كل تحديث للبيانات |
| `sw.js` · `manifest.webmanifest` · `icons/` | التثبيت على الجوال والعمل بدون إنترنت |

لا تغيّر اسم المستودع: تغييره يغيّر الرابط، فيحتاج من ثبّت التطبيق إلى تثبيته من جديد.

## الأمان (تحديث 25-11-2026)
- **لا مكتبات أو خطوط من جهات خارجية:** كل الملفات تُخدم من المستودع نفسه، وسياسة أمان المحتوى (CSP) في الصفحتين تمنع تشغيل أي كود من خارجه أو كود مضمّن في الصفحة.
- **الروابط:** لا يُعرض رابط مصدر إلا إذا كان http/https.
- **رمز الإدارة:** لا تُحفظ بصمته في المتصفح؛ يُعاد التحقق من الرمز في كل جلسة. التحقق يجري في المتصفح، فهو يخفي أدوات الإدارة ولا يحمي البيانات؛ صلاحية النشر الفعلية هي حساب GitHub.
- **ملفات Excel المرفوعة:** تُقرأ داخل Web Worker معزول، بحد أقصى 15 ميغابايت و20 ثانية.
- **طلبات التحديث:** القيم المقترحة والمصدر تُقرأ فقط من طلبات أنشأها سير العمل (`github-actions[bot]`)؛ أي Issue آخر يحتاج كتابة القيم صراحة في تعليق الاعتماد.
- **سير العمل:** إصدارات Actions مثبّتة بمعرّف الإصدار (SHA) ويحدّثها Dependabot شهرياً. لا كلمة مرور افتراضية للإكسل: إن غاب السر `EXCEL_PASSWORD` تُستخدم كلمة عشوائية.
- **قائم ويحتاج قراراً إدارياً:** المستودع عام، فكل البيانات وسجلها منشورة. التفاصيل في التقييم الأمني.
